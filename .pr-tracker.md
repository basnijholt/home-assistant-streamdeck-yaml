### #142 - Allow empty text with "" ✅ MERGED
- **Files**: `home_assistant_streamdeck_yaml.py`, `tests/test_app.py`
- **Purpose**: Allow `text=""` to explicitly show no text, while `text=None` uses defaults
- **Changes during review**:
  - Fixed `close-page` special type that was missed (still used old `text or "Default"` pattern)
  - Added `test_empty_text_button()` and `test_empty_text_render()` tests
- **How it works**:
  - `text: str | None = Field(default=None)` allows distinguishing empty from unset
  - Old pattern: `text = button.text or "Close\nPage"` treats both `None` and `""` as falsy
  - New pattern: `if text is None: text = "Close\nPage"` preserves empty string
- **Status**: Merged 2025-12-23
